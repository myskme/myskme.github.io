# MYSKME · Make Yourself Special & Kind

MYSKME 棋室 3.2.0 正式版是一间明亮、友善、有自己风格的原创棋室。围绕「特别一点，温柔一点」设计品牌与玩法：在经典围棋、五子棋之外，加入成长花园、KataGo 本机陪练、关键手复盘教学、同屏合作棋题、无损分支推演与善意签名卡。保留原版本的全部经典对局能力和浏览器存储键。

本仓库的运行源码在 `../boardroom/`（相当于本文提及的 `dist/`）。请完整克隆仓库并在此目录执行下面的命令；测试和发布脚本已指向实际运行目录。

## 运行与验证

```sh
npm start
# http://localhost:4173
npm test
```

无构建、无需安装 npm 运行依赖，完整发布目录为 `dist/`，包含 KataGo WebAssembly 和两份训练模型。使用 ES Modules 和 Web Worker，需经 HTTP 服务访问。字体可选加载 Google Fonts，失败时回退系统字体。

## 3.2 正式发布

- **棋盘常驻屏幕**：对弈和独立练习使用动态视口，手机无需上下滚动寻找棋盘和落子按钮；设置、提示与教学说明在可关闭的面板中阅读。花园首页、记录和课堂保留自然阅读滚动。短屏横向对弈采用棋盘与操作并排布局。
- **完整备份与迁移**：偏好设置可导出 JSON 备份；导入前显示内容数量，确认后合并棋谱、课程、成长种子与合作收集。已有棋谱和未完成经典棋局优先保留，可选择是否导入昵称和配色。恢复时重新验证真实棋步、提子与继续数子的标记；格式错误不会写入，存储失败会尝试回滚。本机其他应用的数据不在备份范围内。
- **独立静态发布**：资源、ES 模块、轻量 Worker 和 KataGo Worker 均使用相对路径，既可部署到网站根目录，也可部署到 `/boardroom/` 等子目录。每个发布包附文件字节数与 SHA-256 清单。顶栏提供返回 MYSKME 主页的入口。
- **可见的引擎状态**：手机棋盘旁显示真实下载、思考、失败和重试状态，失败后可主动切换轻量陪练。

生成并验证部署目录：

```sh
python scripts/export-release.py --output /tmp/myskme-boardroom-3.2.0
python scripts/check-release.py /tmp/myskme-boardroom-3.2.0
```

把生成目录的全部文件原样放进静态站点的 `boardroom/` 目录；目录网址需以 `/` 结尾。GitHub Pages 项目根目录需有 `.nojekyll`。部署服务须将 `.js` 作为 JavaScript、`.wasm` 作为 `application/wasm` 返回；模型的 `.bin.gz` 是引擎使用的压缩文件，不能额外设置 `Content-Encoding: gzip`。不需要 API 密钥、服务器或跨源隔离头。切勿把整个站点替换为棋室目录。发布变更和验收范围见 [RELEASE.md](RELEASE.md)。

旧网址与新网址拥有各自独立的浏览器存储，记录不会自动跨域迁移。请保留旧网址的数据；已有完整备份可在正式版偏好设置中导入。SGF 与签名卡仍可作为独立文件导出。

## 3.1 成长花园 · A Little Growth, A Little Joy

- **两条 8 课路线**：五子棋覆盖横、竖、两条斜线、补断点、防守、攻守次序与双重成五点；围棋覆盖气、边角、整块提子、打吃解救、连接、提子与自杀禁手、中国数子归属。16 个手工局面均按真实规则校验，起始棋子没有无气死块或已成立的五子连线，每题有明确的一手目标。
- **每日 3 题，约 3 分钟**：优先推荐未完成课程，当天题单固定；掌握全部路线后按日期轮换复习。三层提示可随时使用，错误尝试不扣进度。每日每条路线完成 3 题可再获一颗种子，重复练习不会重复领取首次奖励。
- **把自己的关键手变成练习**：教学复盘中点击「收进成长花园」，收藏最多 24 个包含完整前序棋谱的独立局面。先落下自己的选择，再展开参考、切换比较、逐手看参考变化或自由推演。围棋有限搜索参考不判定为唯一正确答案，也不把原谱点差冒充对玩家新走法的估分。
- **独立练习棋盘**：手机先选点、再确认；支持坐标、键盘、提示、悔棋、黑白自由变化和刷新恢复。个人练习保留提子、盘面超级劫和继续数子的历史标记。练习与推演不覆盖经典棋局、原棋谱或胜负记录。进入花园会暂停原局思考，返回棋室再恢复电脑应手。
- **会生长的原创花园**：练习、发现、善意三盆嫩芽，按对应真实完成记录生长；成长种子以独立事件去重记录。已有双生共弈花朵和善意留言会迁入花园。看原手并比较建议、重练个人局面、合作通关或留句善意，各按来源首次计入成长。
- **6 件可以真正使用的收藏**：2 / 4 / 7 / 11 / 16 / 23 颗种子分别解锁「晨雾薄荷」配色、「小雏菊」花印、「花间来信」卡片装饰、「晴光蜂蜜」配色、「星愿」花印、「星光明信片」装饰。配色覆盖全站和棋盘，花印用于真实最后落子，装饰绘入 960 × 1240 PNG 签名卡。原有三套配色保持可用。
- **本机保存**：使用新增 `myskme:garden-v1` 与 `myskme:garden-draft-v1` 键，保留既有对局和偏好数据。花园不跨设备同步，清除站点数据会移除成长记录。训练内容无需围棋模型下载，个人练习复用已保存的复盘报告。

## 3.0 本机陪练与复盘教学

- **围棋 KataGo 陪练**：实际编译原生神经网络评估、规则与浏览器版 PUCT 搜索。轻松、进阶使用 b6c96；挑战使用更大的 b10c128，搜索上限分别为 3 / 20 / 48 次与 0.4 / 1.4 / 3.2 秒预算。实际耗时随设备而变，不标注未经验证的段位。可用时尝试 WebGPU，否则用 CPU 运行相同模型。
- **按需加载与真实状态**：首次约 5 MB / 12 MB，SHA-256 校验并写入本机 Cache API 缓存；首页不预载模型。显示加载字节、实际完成搜索次数、耗时与后端；失败时允许重试，或由玩家主动选择轻量陪练。切换、悔棋或中止会终止旧 Worker，过期结果不会落子。
- **围棋关键手教学**：快速 / 深入两档，先从阶段覆盖和提子、一口气等真实棋形筛选最多 14 / 24 处，再搜索比较最多 6 个节点。呈现最多三手、原手与参考手、落子方视角的点差估计和可验证的局部说明。明确展示观察范围，抽样结果不宣称是整局最大失误排名。
- **五子棋关键手教学**：直接成五、漏掉制胜点、唯一成五点防守与多点威胁由实际规则校验；其余为有限深度搜索建议，不编造胜率或围棋点差。
- **看原手 → 看建议 → 亲手试**：终局弹窗和每条记录都有教学入口；棋盘区分琥珀原手与绿色参考手，支持参考变化和一键进入独立推演分支。分支不会覆盖原谱。短棋局只展示实际可分析的节点。
- **完成后缓存**：整轮成功才把报告写回原记录，以棋谱、执子方、模式和恢复标记的指纹校验；错误、中断和过期结果不覆盖既有报告。重新打开已分析棋谱可直接查看。
- **本机处理**：棋谱和推演均不上传，无 AI API 密钥和推理服务费用。点差是有限模型与搜索预算下的估计，终局仍需确认死子与数子。

[引擎来源、补丁、模型、许可与可复现编译](third_party/KATAGO.md)。浏览器里的「分析来源与范围」也链接完整来源和开源许可。

## 原创品牌与个性棋室

- 「善意之芽」标志：两片方向不同的叶子合成一颗向上的心，配一枚星点。
- 晴日青柠、蜜桃花园、晴空来信三套完整配色，覆盖界面、棋盘及签名卡。
- 棋手昵称、落子花印、坐标、手数、音效、减少动画与精确落子偏好。
- 手机 19 路棋盘默认先选点再确认，可改为始终确认或直接落子；方向键选点，回车直接确认。
- 高分辨率 Canvas 棋盘、合成音效、轻量落子涟漪与专注模式。

## 原创「双生共弈」

9 路同屏合作棋题，黑白轮流，共享六手，双方都连出五子才获胜。一方连五不会提前结束；琥珀星形种子为不可落子点。三道手工棋题「留一条路」「向光交汇」「彼此成全」都有经测试的解法。支持悔棋、失败后再试、刷新恢复与独立的三朵共弈花朵收集；不混入经典胜负记录。适合一个人思考或两个人面对面合作。

## 经典对弈与灵感陪练

- 五子棋：15 路自由规则，横竖斜连五，长连有效，无禁手。
- 围棋：9 / 13 / 19 路，中国数子法，白贴 7.5 目；气、整块提子、自杀禁手和盘面超级劫。
- 人机练习与同屏双人，三个电脑难度，选择黑白；支持悔棋、提示、停一手、认输。
- 挑战五子棋采用有约 700ms 预算的迭代加深搜索（至多四层），在 Worker 中运行，只保留完整搜索轮次的结果。先处理直接获胜与防守。
- 提示讲解真实的局部棋形：成五点、防守、多重威胁，或围棋提子、气与连接；不生成虚构胜率。
- 围棋连续两次停一手后，手动标记死子、确认数子或继续对局。复杂死活需玩家自行下清楚。可选 KataGo 神经网络陪练或轻量启发式练习；旧棋局保留原有引擎标记。
- 三道每日练习与四张基础教学卡。

## 分支复盘、珍藏与签名卡

完成的最近 100 局自动保存，支持逐手回放、滑动手数和 SGF 导出。在未终局的历史节点点击「从此处推演」，黑白同屏自由尝试另一种走法。分支悔棋不能越过起点，随时回到原谱；分支结束不会覆盖或新增经典记录。

每局终盘可写入预设的善意留言、珍藏棋谱，并生成真实终局棋形的 960 × 1240 PNG 签名卡。图片带个人昵称、对局日期、手数、留言与 MYSKME 标志，可独立选择三套卡片配色。仅下载图片，不自动向任何人发送消息。

对局、昵称、偏好、留言与共弈收集均保存在当前浏览器 localStorage，不跨设备同步。原版本记录兼容。清除站点数据会移除记录，请先导出完整备份、SGF 或签名卡。当前提供本地人机与同屏双人，没有远程联机或在线匹配。
