# MYSKME 棋室 3.2.0

正式版，2026-10-27。基于棋室 3.1.0 的成长花园版本，原始源码提交 `355de447fbf5fdb33596e7fa2985e6c115a4250a`。本版保留经典围棋、五子棋、本机 KataGo、教学复盘、双生共弈、成长课程与签名卡，增加独立部署、固定棋盘和完整备份恢复。

## 使用

打开棋室后即可下棋。手机点「设置」切换围棋、执子、难度与同屏双人；19 路默认先选点再确认。围棋 KataGo 模型首次按需下载，约 5 / 12 MB，失败可重试或主动选轻量陪练。双方停一手后进入死子标记与中国数子，支持继续对局。

对局结束可查看最多三处关键手教学，把局面收进成长花园。花园有两条八课路线与每日三题，完成真实练习、合作和善意事件可获得配色、花印与签名卡装饰。棋谱与推演本机处理；模型建议为有限搜索参考。

偏好设置中的「导出完整备份」保存棋谱、收藏、昵称、配色、未完成棋局、花园与合作进度。换设备时打开同一正式版，选择「导入备份」，查看数量后合并；可关闭昵称与配色导入。备份可能含个人昵称和留言，应由棋手自行保管。

## 发布验收

- 112 项自动检查：围棋规则、超级劫、继续数子、共弈解法、复盘语义、课程与成长去重、真实 b6/b10 WASM、备份重放与合并、存储失败回滚。
- 浏览器完整旅程：围棋提子、双方停一手、继续后再数子；五子棋终局、关键手教学、收藏个人练习、比较与自由推演；手机每日三题；三道合作棋题；真实 SGF 与 960 × 1240 PNG 下载。原始棋谱在练习与推演后保持不变。
- 手机与桌面：320 × 568、390 × 844、412 × 915、768 × 1024、1024 × 768、1440 × 1000，以及 844 × 390 横屏对弈；棋盘在视口内、无横向溢出，长内容面板可滚动与关闭。
- 子目录实际运行：`/boardroom/` 下真实 b6 陪练、b10 提示、模型下载失败后重试、完整备份导出与新浏览器恢复。运行时与模型逐文件校验。

## 部署和回退

`dist/` 是运行源码，发布脚本仅复制静态文件，不读取凭据或玩家数据。`release.json` 标识应用、稳定版本、每个文件的字节数与 SHA-256。部署前运行 `npm test`、导出脚本及发布检查，随后从实际导出目录进行浏览器验证。不要直接发布尚未通过验收的工作目录。

在已有网站中只增加独立棋室目录及入口。当前正式主页若与其 GitHub 源码不一致，应先确认正确源码，再修改主页和触发生产部署，避免用旧页面覆盖新版。GitHub Pages 可以独立承载棋室。

需要回退时恢复上一个棋室目录的 Git 提交，不更改站内其他应用。此版未更名或删除原有 localStorage 键；存储属于浏览器与来源域名，迁移域名不能自动迁走旧记录。回退前先导出完整备份。

## 范围

提供人机和同屏双人，不包含远程在线匹配、云账号或云存档。围棋复杂死活需要玩家确认死子与终局数子；棋力未经过职业等级或世界排名基准测试。KataGo、浏览器移植、模型与依赖的固定来源和完整许可见 [third_party/KATAGO.md](third_party/KATAGO.md) 与 `dist/vendor/katago/NOTICE.txt`。
